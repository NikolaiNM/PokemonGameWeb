# Битва Покемонов (Веб-версия)

Веб-версия консольной игры на Spring Boot + Thymeleaf.

## Стек
- Java 17
- Spring Boot 3
- Maven
- Thymeleaf

## Запуск

1. Открой проект в IntelliJ IDEA.
2. Правой кнопкой на `pom.xml` → **Maven** → **Reload Project**.
3. Дождись окончания загрузки зависимостей.
4. Запусти `PokemonGameWebApplication.java` (зелёный треугольник рядом с `main`).
5. Открой в браузере: http://localhost:8080

## Как играть
- `new` — создать тренера (через форму на главной).
- `add` — поймать покемона по имени.
- `search` — найти 4 диких покемонов.
- `attack` — выбрать своего покемона и атаковать врага.
- `save` / `load` — сохранить/загрузить прогресс.
- `reset` — начать заново.

## Сохранения
Файл `savegame.csv` создаётся в папке `saves/` в корне проекта.
